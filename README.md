# lesh-marketplace

Plugins:

| Plugin | Current version |
|---|---|
| lesh-common-plugin | **1.6.0** |
| english-tutor-plugin | **1.2.1** |

## Install plugin

```bash
claude plugin marketplace add LeshLiao/lesh-marketplace
claude plugin install lesh-common-plugin@lesh-marketplace
claude plugin install english-tutor-plugin@lesh-marketplace   # only on machines that run the english-tutor project
```
- Restart Claude Code

## Update plugin

```bash
claude plugin marketplace update lesh-marketplace
claude plugin update lesh-common-plugin@lesh-marketplace
claude plugin update english-tutor-plugin@lesh-marketplace
```
- Restart Claude Code
